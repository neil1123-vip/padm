# 静态站点与自有网站

优先接入你实际拥有、会持续维护的网站。`站点与证书` -> `本地静态站点` 首先提供 `import`，从独立目录导入完整静态网站；`sites/` 中的 3 套内置布局用于没有现成网站时初始化，不是抗识别保证。

## 导入自有网站

先在独立的绝对 Linux 目录中准备首页、文章、图片、导航和内页，例如 `/srv/own-site/`，再从菜单选择 `import` 并输入该目录。安装器原样复制完整内容到 `nginxStaticPath`，默认 `/usr/share/nginx/html/`，不替换导入网页的标题、文案、图片或样式。导入是一次复制；修改源目录后，需要再次导入才会更新目标网站。

源目录必须含可读 `index.html`，且与目标目录互不包含、互不重叠。目录和文件名称暂限 `A-Za-z0-9_./-` 字符，不接受点文件、符号链接、硬链接、特殊文件，以及 `check` 或 `static-site.json`。导入前应将构建产物整理为符合这些条件的静态目录。

导入复用暂存校验、原子目录替换与失败回滚。明确替换自有或修改过的网站前，持久私有备份保存在 `/etc/padm/static-site-backups/`；未修改的内置主题只保留用于失败回滚的事务临时备份，不为每次切换保存档案。归属状态保存在公开目录之外的 `/etc/padm/static-site.json`。自动安装不覆盖已有或修改过的网站；自有或导入网站即使未修改，卸载也会保留。

仅含未修改的 Nginx 官方新旧 `index.html` 和可选 `50x.html`、且没有站点状态的目录视为默认占位页，安装主题时可直接替换，并保留失败回滚备份。识别使用完整内容的 SHA256；页面被修改、出现额外文件或目录、链接或站点状态时，继续按已有网页保护。

Nginx 在自有网站提供 `404.html` 时使用该页面并保持 HTTP 404 状态；没有该文件则使用默认 404。sing-box `file://` 文件服务的未知路径使用 Go 默认 404 文本，不自动加载 `404.html`。

## 内置布局

`sites/` 中的内容不依赖 CDN、远程字体或 JavaScript 框架。

| 目录 | 内容 | 排版 |
| --- | --- | --- |
| `notes` | 阅读、散步、笔记索引、重读、天气声音、开放问题与街道记忆，8 篇完整文章及关于页 | 单栏衬线长文、按日期排列的文章列表 |
| `photos` | 林间光线、山脊观察、照片编排、空间、色彩、边界、观看尺寸与图注，8 篇摄影文章及关于页 | 大图、双栏摘要、独立摄影正文 |
| `docs` | 个人摄影归档手册，文件整理、备份导出、复查、保留选择、交付、记录、校验与迁移，8 篇正文及关于页 | 侧栏目录、表格、代码示例、原生可展开问答 |

每套布局含 `index.html`、`404.html`、完整内页、`assets/style.css` 和 PNG 图标。所有文案均为独立撰写，不虚构作者履历、机构、项目用户或拍摄经历。摄影文章是对公开许可照片的视觉观察。

菜单可配置站名；默认站名与配色固定，安装状态保存所选值，同主题重装保持稳定。安装后应像正常网站一样维护真实文章、图片、导航和内页。整套内容与配置要一起更新时，在独立目录准备网站后使用 `import`，没有自动编造内容或随机改写外观的流程。同一布局的安装仍共用 HTML/CSS 结构，标题、颜色或正文差异不能证明其不可识别。

## 安装占位符

- `sites.sha256` 登记随包资源的路径和摘要，运行时不重新生成；更新资源时同步提交清单。当前三套主题共 43 个资源。
- `__SITE_TITLE__`：HTML 的页面标题、站点品牌与必要正文；替换值必须经过 HTML 转义。
- `__SITE_ACCENT__`：CSS 主色，仅接受有效的十六进制颜色。
- 占位符仅用于初始化内置布局，不处理导入的原始网页。站点主题、站名与配色由安装状态保存。
- 站点目录不包含安装状态、归属标记或 `check`。本 README 不应复制到公开网页目录。

## Docker 内置站点

Docker 菜单 `16. 站点管理` → `8. 内置静态站点`，或
`padm-docker edit --site-template notes|photos|docs`，可在已有 v3 Xray Nginx TLS
`21–25` 或 fallback `27/29` 部署中发布主题。包含 sing-box `23` 或 Hysteria2
的部署明确拒绝；其它不提供网站的 Reality 入口可共存。

当前和候选控制包都须声明 `x-padm-site-templates` 并完整携带随包清单和资源。
模板从受管候选包复制，使用默认站名与配色；生成后只保存普通 `site.mode=static`，
不保存主题身份。预览、取消、备份、恢复及后续静态目录发布沿用站点事务，
代理、订阅、证书及 ACME 路径保持。旧包仍可使用其已有默认页、静态目录和 302。

## Hysteria2 接入

原生 Hysteria2 的“认证失败伪装”可以直接填写 `file:///srv/own-site/` 使用独立自有网站目录，也可填写受你控制的网站 `http://` 或 `https://` URL 进行反向代理。填写 `local` 使用当前本机网页，或填写 `notes`、`photos`、`docs` 初始化内置布局。文件目录同样需要可读首页，并满足上面的目录内容限制。

启用混淆后，普通浏览器不能通过标准 HTTP/3 访问该入口。Docker Hysteria2 的本地网页未接入，保持现有远程 HTTPS 伪装。

协议与配置说明：[Hysteria2 协议](https://v2.hysteria.network/docs/developers/Protocol/)、[sing-box Hysteria2 入站](https://sing-box.sagernet.org/configuration/inbound/hysteria2/)。

## 检查范围

部署前应检查内置布局的占位符已替换、内部链接和片段存在、本地图片与 CSS 可读取，以及手机和桌面宽度下的导航、标题和正文。对自有网站还应验证导入后文章与资源保持完整。网页内容与外观不能证明特定网络环境下的不可识别性。
