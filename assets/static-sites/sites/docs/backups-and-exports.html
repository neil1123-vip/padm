Keeping work available

Backups and exports

An archive is ready to use when its originals have a separate copy and its finished versions can be opened without the editing application.

Make the copies independent

A second folder on the same disk does not protect against that disk failing. Keep an additional copy on a different device or service. Where possible, keep one copy away from the place where the main archive is stored.

Decide which folders belong in the backup. Originals, collection notes and the editing instructions that cannot be recreated quickly usually matter most. Finished exports are often worth keeping too, especially if a particular version has already been delivered.

Synchronisation and backup answer different questions. A synchronised deletion can remove a file everywhere. Check whether your chosen system retains earlier versions and deleted files.

Try a small recovery

  1. Choose a collection that has already been copied.
  2. Restore one original, one export and the collection note into a temporary folder.
  3. Open the restored photographs and read the note.
  4. Compare the file sizes and, if your tools support it, file checksums.
  5. Record the date and the result before removing the temporary recovery copy.

Repeat this after changing the backup software or destination. A check of a few files does not prove that every file is recoverable, but it can reveal a wrong folder selection, an unreadable format or a missing credential before the archive is needed.

Before sharing an export

  • Open the actual exported file, not the editing preview.
  • Confirm its dimensions and format match the destination.
  • Review the crop at the size at which the photograph will be seen.
  • Check embedded location and personal information before sharing publicly.
  • Keep the export beside the source, with a name that describes its use.

Common questions

Should every editing experiment be kept?

Keep versions that explain a meaningful decision or would take time to reproduce. Disposable experiments can stay in the working folder until the collection is settled.

Is a web export a replacement for the original?

No. A web export often has reduced dimensions, compression and a fixed crop. Retain the original so future uses are not limited by those choices.

How often should a new copy be made?

Make a copy after an import or a substantial editing session. The useful interval is the amount of work you are prepared to repeat if the main copy is lost.
