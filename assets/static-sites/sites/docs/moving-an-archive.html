Changing storage

Moving an archive

Move a photography archive in stages so the old copy remains available until the new one has been opened, checked and understood.

A new disk or folder is a chance to improve the structure, but combining a move with a full rename makes errors harder to locate. Keep the first pass faithful to the existing archive.

Prepare before copying

Write down the source path, destination path and the editing application or catalogue that refers to the files. Check available space and make sure the destination can store the largest source files without a format change.

  • Pause automatic cleanup while the move is in progress.
  • Keep the original copy untouched.
  • Choose one small collection for a trial move.

Copy, compare and open

Copy one collection first. Compare a sample as described in Checking file integrity, then open the source, an export and the collection note from the new path.

Only after the trial works should you copy the remaining collections. Preserve folder names and file names so an editing catalogue can be relinked in one predictable step.

Old: /archive/photographs/
New: /media/photo-archive/photographs/
Trial: 2025-09-woodland/
Result: sample opened; catalogue path updated

Switch the working path deliberately

Update the editing application to the new root and test a few older projects. Do not erase the old copy when the first project opens; a missing link may only appear when a less recent collection is selected.

Keep the old copy until the new archive has passed a recovery check and the collection notes identify the new destination. Then label the old disk clearly as an archive or backup so it is not mistaken for the active working copy.

A move is complete when the files, the notes and the application all agree about where the collection lives.

If the move also requires a new naming rule, make that a separate, documented change. A stable copy gives you a reference when the later cleanup raises a question.
