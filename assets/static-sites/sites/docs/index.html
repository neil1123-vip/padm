Overview

__SITE_TITLE__

Keep photographs understandable outside the application that made them. This handbook describes a small archive built from ordinary files, folders and a clear index.

A good archive should answer three questions without much searching: where are the originals, which version is ready to share, and is there another copy if a disk fails?

Where to start

Begin with a single collection rather than reorganising every disk at once. Choose one group of photographs, give it a dated folder and separate the camera files from the versions intended for sharing.

Working principles

  • Keep originals intact. Editing should produce a new file or a separate set of instructions.
  • Use names that survive a move. A date and a short subject are more useful than an application-specific identifier.
  • Check recovery. The existence of a backup is less useful than knowing that a file can be restored from it.

This is a workflow guide, not a requirement to use particular software. Follow the parts that make your own collection easier to understand.

Once a collection is settled, leave a short review note beside it. A future check can then start with what changed, rather than reconstructing every decision from the file names.
