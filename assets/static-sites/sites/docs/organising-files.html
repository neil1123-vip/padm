Working with a collection

Organising files

Separate the original material from the finished versions, then keep enough context beside them to explain what belongs together.

A folder for each collection

Use a collection folder to describe an event or a small body of work. A date at the beginning keeps folders in a predictable order. A short subject makes them readable without opening each one.

photographs/
  2025-09-woodland/
    originals/
    working/
    exports/
    collection.txt
ItemPurpose
originals/Files copied from the camera or source. Keep these unchanged.
working/Edit instructions and intermediate versions that are still in progress.
exports/Finished files intended for a specific use, such as web or print.
collection.txtA plain text note describing the collection and the important versions.

There is no need to create an empty working folder if the editing application keeps its instructions elsewhere. What matters is being able to identify the originals and exports consistently.

Names that remain readable

Camera names are often unique only within one card or one camera. Add a collection prefix when importing into the archive, or retain the camera name inside a uniquely named collection folder.

2025-09-04_woodland_001.jpg
2025-09-04_woodland_001_web.jpg
2025-09-04_woodland_001_print.tif

Keep the part that identifies the photograph the same across its versions. Put the intended use at the end. Avoid adding words such as final-final; if revisions matter, use a small version number and record the choice in the index.

A short collection index

The index should help somebody understand the folder without the original editing application. Include the subject, the approximate dates and any file that deserves special attention.

Collection: Woodland light studies
Date: September 2025
Originals: unchanged source files
Web selection: 001, 004, 012
Print selection: 004
Notes: web exports use the smaller crop

Write enough to be useful after six months, but not so much that maintaining the note becomes another project. When a collection changes, update the index while the decision is still fresh.
