About

A handbook for a small archive

__SITE_TITLE__ describes a practical file-based workflow for a personal photography collection. Its goal is to make the collection understandable when it is opened on a different computer, or after a long break.

What it covers

The handbook focuses on folders, file names, collection notes, independent copies and finished exports. It is intended for a small collection maintained by one person, not a shared institutional archive.

What to adapt

Use a folder structure that matches how you look for photographs. Dates are helpful, but a long project may deserve a subject folder that contains several dated collections. Keep the naming rules simple enough to use consistently.

Storage software, camera formats and delivery requirements vary. Check the tools you use with a few real files before applying a new workflow to the entire archive.
